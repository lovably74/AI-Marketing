# 내장 폰트

PDF 브로셔(`src/lib/export/pdf.ts`)의 한글 렌더링에 사용한다. pdfkit 기본 폰트(Helvetica)는 한글을 표시하지 못한다.

| 파일 | 출처 | 라이선스 |
|---|---|---|
| NanumGothic-Regular.ttf | https://raw.githubusercontent.com/google/fonts/main/ofl/nanumgothic/NanumGothic-Regular.ttf | SIL Open Font License 1.1 |
| NanumGothic-Bold.ttf | https://raw.githubusercontent.com/google/fonts/main/ofl/nanumgothic/NanumGothic-Bold.ttf | SIL Open Font License 1.1 |

- 저작권: NHN Corporation(현 NAVER, 나눔고딕) — OFL.txt 첫 줄 기준. 라이선스 전문은 같은 폴더의 `OFL.txt`(google/fonts 저장소 원본).
- 내려받은 날짜: 2026-11-20
- OFL에 따라 폰트 파일 자체의 단독 판매는 금지되며, 문서에 임베드(서브셋)하는 것은 허용된다.
