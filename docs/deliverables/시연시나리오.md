# T-LINK AI Marketing Studio 시연 시나리오

- 문서 버전: v0.1 (2026-11-20, 리허설 기준)
- 산출물: `시연영상/TLINK_시연영상.mp4`(1280×720, H.264 + AAC), `시연영상/TLINK_시연영상.srt`, `시연영상/내레이션_원고.txt`
- 내레이션: Windows TTS "Microsoft Heami Desktop"(ko-KR, System.Speech)로 장면별 WAV 생성
- 자막: SRT 생성 후 NanumGothic(`studio/assets/fonts`)으로 영상에 입힘
- 개인정보: 수신 고객 정보와 발신 계정 주소는 녹화 시점에 CSS `filter: blur(8px)`로 가림. PDF 미리보기(iframe) 상단(표지 호칭 영역)은 블러 오버레이로 가림. 자막·내레이션에서는 "고객사 담당자"로만 표현
- 관리자 토큰: `.env.local`에서 읽어 password 입력칸에만 입력(화면에는 점으로 표시). 로그·자막·문서에 값을 남기지 않음

## 2. 사전 준비 체크리스트

- [ ] http://localhost:3000, /admin, /history 응답 200 확인
- [ ] `studio/.env.local`에 AI 키, 메일 발송 계정, ADMIN_TOKEN 설정(값은 화면·문서에 노출 금지)
- [ ] 시연 사진 `studio/test-assets/demo/01_사무실_인터넷전화.jpg` 존재
- [ ] 수신 고객(사용자 지정) 정보와 발송 승인 확인 — 본 녹화에서만 실제 발송 1회
- [ ] Playwright(Edge 채널) 및 녹화용 ffmpeg(`npx playwright install ffmpeg`) 설치
- [ ] ffmpeg(`C:\ProgramData\chocolatey\bin\ffmpeg.exe`), 한글 폰트 NanumGothic-Bold.ttf
- [ ] 녹화 후 프레임 추출로 개인정보 블러·토큰 미노출·자막 가독성 확인

## 3. 자동 재생성 명령

작업 폴더(스크립트 위치): 세션 scratchpad의 `video\` 폴더(`narration.json`, `tts.ps1`, `record.js`, `compose.js`, `make-video.cmd`).

```bat
rem 리허설(메일 발송 없음, 확인 대화상자에서 취소)
make-video.cmd
rem 본 녹화(실제 메일 1회 발송)
make-video.cmd send
```

처리 순서: TTS WAV 생성(없을 때) → Playwright 녹화(장면별 내레이션 길이만큼 화면 유지, 시각 기록) → ffmpeg로 AI 대기 구간 삭제 + 오디오 adelay/amix + 자막 입히기 → `시연영상/`에 MP4·SRT·원고 저장.

## 4. 수동 재녹화 방법(OBS 기준)

1. OBS 캔버스·출력 1280×720(또는 1920×1080), 30fps, 녹화 형식 mp4. 소스: 브라우저 창 캡처 + (선택) 마이크.
2. 브라우저 확대 100%, 북마크바·확장 아이콘 숨김. 개인정보 보호를 위해 수신 고객 정보 입력 장면은 OBS 필터(블러/모자이크 플러그인) 또는 편집 단계에서 가림.
3. 위 장면 표의 순서대로 조작하며 원고를 읽는다. AI 대기 구간은 편집기에서 잘라 내고 "실제 응답 약 ○○초" 자막을 넣는다.
4. 관리자 토큰은 password 입력칸에만 붙여 넣고, 메모장 등 평문으로 띄우지 않는다.
5. 편집 후 `TLINK_시연영상.srt`를 자막 트랙으로 불러와 타이밍을 맞춘다.
