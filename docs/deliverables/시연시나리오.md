# T-LINK AI Marketing Studio 시연 시나리오

- 문서 버전: v0.2 (2026-11-20, 통합본 main 3dbeaa6 화면 기준 재제작). v0.1은 `Backup/시연시나리오_v1_20261120.md`
- 산출물: `시연영상/TLINK_시연영상.mp4`(2분 6초, 1280×720, H.264 + AAC), `시연영상/TLINK_시연영상.srt`, `시연영상/내레이션_원고.txt`. 이전 영상(v1)은 `시연영상/Backup/`
- 내레이션: Windows TTS "Microsoft Heami Desktop"(ko-KR, System.Speech, 속도 +1)로 장면별 WAV 생성
- 자막: SRT 생성 후 NanumGothic(`studio/assets/fonts`)으로 영상에 입힘
- AI 대기: 실제 응답 약 29초(본 녹화 실측)를 편집으로 잘라 내고 자막으로 표기. 메일 발송 대기(약 11초)도 잘라 냄
- 메일 발송: 본 녹화에서 수신 고객(사용자 지정, 사용자 승인)에게 실제 1회 발송·성공. 리허설은 확인 대화상자에서 취소
- 개인정보: 수신 고객의 이름·회사·부서·직함·이메일·연락처와 발신 계정 주소가 보이는 요소(입력칸, 받는 사람, 메일 제목·본문, 확인 대화상자, 성공 메시지, 이력 수신자)를 녹화 시점에 CSS `filter: blur(8px)`로 가림. PDF 미리보기(iframe)는 표지 호칭이 있는 상단 45%를 블러 오버레이로 가리고, 오버레이 적용 전 약 2초 구간은 합성 단계에서 ffmpeg boxblur로 추가 처리(timeline의 `blurBoxes`). 자막·내레이션에서는 "고객사 담당자"로만 표현
- 관리자 토큰: `.env.local`에서 읽어 password 입력칸에만 입력(화면에는 점으로 표시). 로그·자막·문서에 값을 남기지 않음

## 3. 자동 재생성 명령

스크립트: `시연영상\스크립트\`(git 제외 폴더, `narration.json`, `tts.ps1`, `record.js`, `compose.js`, `make-video.cmd`). 녹화 결과는 `timeline_<rehearsal|main>.json`·`raw_<TAG>.webm`으로 남고, 녹화가 중간에 실패해도 기록된 장면까지 합성할 수 있다(발송 이후 실패 시 재발송하지 않고 `node compose.js <출력폴더> main`만 다시 실행).

```bat
rem 리허설(메일 발송 없음, 확인 대화상자에서 취소)
make-video.cmd
rem 본 녹화(실제 메일 1회 발송)
make-video.cmd send
```

처리 순서: TTS WAV 생성(없을 때) → Playwright 녹화(장면별 내레이션 길이만큼 화면 유지, 시각 기록) → ffmpeg로 AI·메일 발송 대기 구간 삭제 + 추가 블러 상자(blurBoxes) + 오디오 adelay/amix + 자막 입히기 → `시연영상/`에 MP4·SRT·원고 저장.

## 4. 수동 재녹화 방법(OBS 기준)

1. OBS 캔버스·출력 1280×720(또는 1920×1080), 30fps, 녹화 형식 mp4. 소스: 브라우저 창 캡처 + (선택) 마이크.
2. 브라우저 확대 100%, 북마크바·확장 아이콘 숨김. 개인정보 보호를 위해 수신 고객 정보 입력 장면은 OBS 필터(블러/모자이크 플러그인) 또는 편집 단계에서 가림.
3. 위 장면 표의 순서대로 조작하며 원고를 읽는다. AI 대기 구간은 편집기에서 잘라 내고 "실제 응답 약 ○○초" 자막을 넣는다.
4. 관리자 토큰은 password 입력칸에만 붙여 넣고, 메모장 등 평문으로 띄우지 않는다.
5. 편집 후 `TLINK_시연영상.srt`를 자막 트랙으로 불러와 타이밍을 맞춘다.
