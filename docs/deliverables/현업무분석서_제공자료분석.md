## 6. 불일치·주의사항

1. **SHA256 미확인**: xlsx 미션 11은 "AES256·SHA256 암호화"를 요구하지만, 제품 자료에는 "AES256 녹취파일 암호화"(제안서 S3)만 있음. SHA256은 근거 없음 → 가이드라인 지시로 쓰되 지식베이스에는 넣지 않음. 고객사 확인 권장.
2. **"고객 이탈 위험"** (xlsx 컨셉·미션 6): 제품 자료에서 "이탈"이라는 표현 미확인. 가장 가까운 근거는 RED 알림(같은 이슈 3회 반복 시 긴급 리스크 경보, 제안서 S6), VOC 이슈 자동 분류(S7).
3. **"고객 요청사항과 후속 조치 내용이 자동 기록"** (미션 3): 통화 단위 자동 기록으로 확인되는 것은 한줄요약·키워드·화자별 대화(제안서 S4, 휴대폰 S7). "권장 후속조치"는 종합리포트의 영업기회 표에 있음(S7). 통화마다 요청사항/후속조치 필드가 자동 생성된다는 근거는 미확인.
4. **"회의록작성"** (서브 키워드·태그): 자료에서 "회의록" 표현 미확인. 대면 녹취(현장 녹음 업로드, 휴대폰 S26) 기능이 관련될 수 있으나 회의록 생성 기능 자체는 근거 없음.
5. **"업무자동화", "콜센터 프로그램", "통화요약"**(필수 키워드) 단어 자체는 제품 자료 원문에 없음(문맥상 대응 기능은 있음). 키워드로만 사용.
6. **PC폰 녹음 제약**: TlinkPhone 녹음은 "삼성 070 계정에서만 사용 가능"(PC폰 16p). "집에서는 PC폰으로 동시에 자동 녹음"(미션 2)을 무조건적으로 표현하면 과장 위험. 또 실시간 STT·통역은 "계정 설정에 따라 사용이 제한될 수 있음".
7. **"조직별" 통계**: 담당자별 통계·팀 관리(멤버 팀)는 있으나 "조직별 리포트"는 명시적 근거 약함.
8. **"경영 대시보드"**: 상시 대시보드가 아니라 종합리포트(기간 선택 생성, PDF) 내 "경영 분석 대시보드". 종합리포트는 별도 요금(10만원/월, 월 3회 생성) 옵션.
9. **수치 사용 주의**: 115건·6건·9개·78점 등은 고객사 예시 화면 값. 일반화 금지. 240건은 가정 계산("하루 1건만 놓쳐도").
10. **도입 기업 수 표기 차이**: "1,000+ 도입 기업"(S3) vs "국내 1,000여 개 기업"(S11). 회사소개서 3p는 "상주인원 7명".
11. **회사 주소 불일치**: 회사소개서 3p "서울시 서초구 서초동 1338-21 코리아비즈니스센터 901호" vs 13p "서울시 서초구 강남대로 309 코리아비즈니스센터 … 901호"(텍스트 일부 깨짐). 마케팅 문구에는 주소 불필요.
12. **연락처 사용 주의**: 회사소개서 13p의 대표 휴대전화(010-…)·개인 이메일은 개인정보이므로 마케팅 콘텐츠에 사용하지 말 것. 공식 연락처는 1877-3836, tlink@tlinkcrm.com(제안서 S10), 02-548-8808(회사소개서 13p).
13. 요금은 "예시 견적"이며 "최종 비용은 상담 후 확정" 문구를 함께 써야 함.
14. 상표등록은 "티링크레코딩", "티링크미니"이며 "티링크 비즈레코딩" 자체의 상표 등록 여부는 미확인.
