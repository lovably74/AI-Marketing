## 1. 배경과 목표

### 1.1 원래 과제 (변경 불가)
> "티링크의 제품과 기술적 차별점을 AI가 분석하고, 현장 사진과 제품 정보만으로 고객의 관심을 끌 수 있는 홍보 콘텐츠를 자동 생성하는 마케팅 솔루션을 개발해 주세요."

### 1.2 핵심 목표 (P0)
| ID | 목표 |
|---|---|
| G1 | AI가 티링크 제품과 기술적 차별점을 **실제로** 분석한다 (고정 문구·사전 결과 금지). |
| G2 | **현장 사진 1장 + 제품 정보**만으로 분석을 시작할 수 있다. |
| G3 | 분석 결과를 근거로 고객 관심을 끄는 홍보 콘텐츠(제목·블로그·SNS·카드뉴스)를 자동 생성한다. |

### 1.3 성공 기준 (완료 기준 — 원 과제 12절)
사진 업로드 → 제품 정보 입력 → 생성 버튼 → **실제 AI API** 차별점 분석 → 편익·근거 표시 → 제목 3종 → 블로그·SNS → 사진 기반 카드뉴스 → 문구 복사 → 카드뉴스 PNG(1080×1080) 다운로드, 그리고 `npm run build` 성공.
API 키가 없거나 실제 호출을 검증하지 못한 항목은 "완료"로 보고하지 않는다.

## 3. 범위

### 3.1 포함
입력 화면, `POST /api/generate`, 결과 화면(A 분석 / B 콘텐츠 / C 카드뉴스), PNG 다운로드, 텍스트 복사, 지식베이스 JSON, 모델 관리 페이지와 API, README 시연 절차.

### 3.2 제외 (원 과제 11절 유지)
회원가입·로그인, DB, 벡터검색·RAG, PDF·PPT 실시간 분석, 실시간 경쟁사 검색, 외부 CRM 연동, SNS 자동 게시, 동영상 생성, 결제, 다중 카드뉴스, 복잡한 관리자 화면(C2의 단순 모델 관리는 예외).

### 4.2 AI 분석 API (FR-API) — `POST /api/generate`
| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-API-01 | multipart/form-data로 image, productName, productInfo, targetCustomer, modelId를 받는다. | P0 |
| FR-API-02 | 서버에서 이미지 형식·크기와 텍스트 길이(제품정보 최대 3,000자)를 다시 검사한다. | P0 |
| FR-API-03 | 현장 사진, 사용자 제품 정보, 티링크 지식베이스, 마케팅 가이드라인을 **한 번의 AI 호출**로 전달한다. | P0 |
| FR-API-04 | AI 작업: ① 현장 사진 분석(보이는 것만, 추측 금지) ② 기술 차별점 3개 선정(고객 문제, 편익, 근거 ID) ③ 콘텐츠 생성(제목 3종, 블로그, SNS, 카드뉴스 제목·부제, CTA, 해시태그) | P0 |
| FR-API-05 | 제공사의 구조화 출력 기능(JSON 스키마)을 쓰고, 서버에서 Zod 스키마로 **다시 검증**한다. | P0 |
| FR-API-06 | 근거 검증: `evidence`는 지식베이스 ID(F001 형식) 또는 `USER_INPUT`만 허용한다. 존재하지 않는 ID가 나오면 1회 재시도하고, 그래도 실패하면 오류로 처리한다. | P0 |
| FR-API-07 | 가이드라인 검증: 필수 키워드(통화요약, 콜센터 프로그램, 업무자동화)가 제목 또는 블로그 본문에 들어갔는지, 금지 표현(허위 사용 후기, 근거 없는 경쟁사 대비 절대우위 표현)이 없는지 서버에서 점검하고 결과를 응답에 담는다. | P0 |
| FR-API-08 | 실패하면(키 없음, 타임아웃, 스키마 불일치, 제공사 오류) 명확한 오류 코드와 메시지를 반환한다. **가짜 결과나 예시 결과로 대신하지 않는다.** | P0 |
| FR-API-09 | 프롬프트 인젝션 방어: 사용자 입력은 `<user_input>` 구분 블록 안에 "데이터"로 넣고, 시스템 지침이 우선함을 명시한다. 사진 속 글자도 지시로 따르지 않는다. | P0 |
| FR-API-10 | 사용자가 티링크 외 제품 정보를 입력하면 입력 내용만 근거(USER_INPUT)로 분석하고, 티링크 고유 기능을 그 제품의 기능이라고 주장하지 않는다. | P0 |
| FR-API-11 | API 키는 서버 환경변수로만 읽고 클라이언트에 노출하지 않는다. | P0 |
