## 1부. 유튜브에 영상 올리기

3. 핸들(@로 시작하는 주소)은 자동으로 제안된 것을 써도 됩니다.
4. **[채널 만들기]**를 누릅니다.

## 2부. 구글 드라이브에 올리고 공유하기

### 2-1. 드라이브 열기
1. 주소창에 아래를 붙여 넣고 Enter를 누릅니다.
   ```
   https://drive.google.com
   ```
2. 오른쪽 위 프로필이 **roitechtube@gmail.com**인지 확인합니다. 아니면 프로필 사진 → 다른 계정 추가 또는 전환을 합니다.

### 2-2. 폴더 만들기 (정리용, 선택)
1. 왼쪽 위 **[+ 신규]** → **[새 폴더]**를 누릅니다.
2. 이름 칸에 아래를 붙여 넣고 **[만들기]**를 누릅니다.
   ```
   T-LINK AI Marketing Studio 워크톤 제출
   ```
3. 만든 폴더를 더블클릭해 들어갑니다.

### 2-3. 파일 올리기
1. **[+ 신규]** → **[파일 업로드]**를 누릅니다.
2. 열린 창의 주소 칸에 아래를 붙여 넣고 Enter를 누릅니다.
   ```
   C:\Project\A-19-로이(2) 프로젝트\시연영상
   ```
3. `TLINK_시연영상.mp4`를 선택합니다. 자막(`.srt`)과 원고(`내레이션_원고.txt`)도 함께 올리려면 **Ctrl 키를 누른 채** 같이 클릭합니다. 그다음 **[열기]**를 누릅니다.
4. 오른쪽 아래에 "업로드 완료"가 표시될 때까지 기다립니다. 영상은 업로드 뒤 처리 시간이 몇 분 걸려야 미리보기 재생이 됩니다.
> 파일 탐색기에서 파일을 드라이브 화면으로 끌어다 놓아도 됩니다.

### 2-4. 링크로 공유하기
1. 올린 `TLINK_시연영상.mp4`에서 **마우스 오른쪽 버튼** → **[공유]** → **[공유]**를 누릅니다.
2. 아래쪽 **"일반 액세스"**에서 **"제한됨"**을 누르고 **"링크가 있는 모든 사용자"**로 바꿉니다.
3. 오른쪽 역할은 **"뷰어"**로 둡니다(다른 사람이 수정하거나 삭제하지 못합니다).
4. **[링크 복사]** → **[완료]**를 누릅니다. 복사한 링크(`https://drive.google.com/file/d/.../view?usp=sharing`)를 제출하면 됩니다.
> 폴더째 공유하려면 2-2에서 만든 폴더를 오른쪽 클릭 → [공유]에서 같은 방법으로 하면, 폴더 안 파일이 모두 공유됩니다.

### 2-5. 특정 사람에게만 공유하기 (보안상 더 안전)
1. 오른쪽 클릭 → **[공유]** → **[공유]**를 누릅니다.
2. 위쪽 **"사용자, 그룹, 캘린더 일정 추가"** 칸에 받을 사람의 이메일을 입력합니다(여러 명이면 Enter로 계속 추가).
3. 역할은 **뷰어**로 둡니다.
4. **"이메일 알림 보내기"**에 체크한 상태로 메시지 칸에 예를 들어 아래를 붙여 넣습니다.
   ```
   T-LINK AI Marketing Studio 워크톤 시연 영상을 공유드립니다. 링크에서 바로 재생하실 수 있습니다.
   ```
5. **[보내기]**를 누릅니다.

### 2-6. 다운로드 막기 (선택)
뷰어가 영상을 내려받지 못하게 하려면 다음과 같이 합니다.
- 공유 창 오른쪽 위 **톱니바퀴(설정)** → **"뷰어 및 댓글 작성자에게 다운로드, 인쇄, 복사 옵션 표시"**의 체크를 해제합니다.

## 3부. 자주 막히는 문제

| 증상 | 해결 |
|---|---|
| 유튜브 업로드 창에 "채널 만들기"가 뜸 | 1-2를 진행합니다(처음 한 번). |
| 15분이 넘는 영상을 올릴 수 없다고 나옴 | 이 영상은 3분 안팎이라 해당하지 않습니다. 긴 영상은 https://www.youtube.com/verify 에서 휴대폰 인증을 하면 올릴 수 있습니다. |
| 썸네일 직접 업로드 버튼이 안 눌림 | 위와 같은 휴대폰 인증이 필요합니다. 자동 썸네일을 써도 됩니다. |
| 자막 업로드 시 오류 | 언어를 한국어로 선택했는지, 파일이 `.srt`인지 확인합니다. 영상에는 자막이 이미 입혀져 있으므로 이 단계는 건너뛰어도 됩니다. |
| 드라이브에서 영상이 "처리 중"으로 재생 안 됨 | 몇 분 기다린 뒤 새로고침합니다. 링크 공유는 그 전에도 됩니다. |
| 받은 사람이 "액세스 권한 필요"라고 함 | 2-4의 일반 액세스가 "링크가 있는 모든 사용자"인지, 또는 2-5에서 그 사람의 이메일을 추가했는지 확인합니다. |
| 다른 계정으로 올라감 | 오른쪽 위 프로필을 roitechtube@gmail.com으로 전환한 뒤 다시 올립니다. 잘못 올린 영상은 1-9 방법으로 삭제합니다. |

## 4부. 보안 주의
- 영상 공개 범위는 **일부 공개** 또는 **특정 사용자 공유**를 권장합니다. 영상에는 고객사명 등 블러되지 않은 업무 정보가 있을 수 있습니다.
- 계정 비밀번호는 이 문서나 메신저에 적지 마세요. 개발 중 대화에 노출된 비밀번호는 변경해야 합니다. 변경하면 메일 발송용 앱 비밀번호도 다시 발급해 `studio\.env.local`의 `SMTP_PASS`에 넣어야 합니다.
